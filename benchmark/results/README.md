# Benchmark results

These CSV files are generated by `robot_self_filter_benchmark` from a Release build. Each case uses a fixed synthetic Mole-like robot and deterministic point cloud. Results used for a release must be captured on the same machine and pinned CPU, with identical warm-up and measured iteration counts.

Compare two runs with:

```bash
python3 test/compare_benchmarks.py \
  benchmark/results/baseline_8910134.csv \
  benchmark/results/optimized_v1.1.0.csv
```

The verifier fails if classification checksums differ, if a case regresses by more than 5%, or if the geometric mean of per-case median-throughput improvements is below 20%.
